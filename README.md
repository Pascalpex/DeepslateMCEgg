# DeepslateMC Pelican Egg 🥚

This repository contains the official [Pelican Panel](https://pelican.dev/) egg for **DeepslateMC**

With this egg, you can easily deploy, manage, and run a DeepslateMC server directly from your Pelican Panel instance.
